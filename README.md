# P.K PRACTICE — Phrasal Verb Learning & Practice

**P.K PRACTICE** is an interactive English-learning web app focused on phrasal verbs (Group Verbs). It helps learners build vocabulary through Bengali meanings, examples, guided learning, quizzes, and friendly real-time challenges.

🌐 **Live Website:** https://parthakonai000.github.io/Group-verb-practice/

---

## ✨ Features

### 📋 Phrasal Verb Library
- Browse the available phrasal-verb collection in a clean list.
- Search using English words or Bengali meanings.
- Sort the list in **A–Z** or **Z–A** order.
- Explore meanings and example-based learning content.

### 📚 Interactive Learning Mode
- Learn phrasal verbs step by step with flashcards.
- Review Bengali meanings and English explanations.
- Use pronunciation/audio support where available.
- Learn at your own pace and strengthen your understanding through examples.

### 🎯 Practice & Quiz
- Test your knowledge with multiple-choice questions.
- Read a Bengali meaning and choose the matching English phrasal verb.
- Complete a 10-question practice round.
- Check your performance and reinforce what you have learned.

### 🎮 Play with Friends — Real-Time 1-vs-1
- Create a game room and invite a friend.
- Join an existing room using its **4-digit room code**.
- Share the room invitation with your friend.
- Both players answer the same set of 10 questions.
- Compete in a live head-to-head quiz.
- Follow both players' scores and progress during the match.
- View the match result and compare scores.
- Start another round or return to the lobby.

### 🔥 Daily Practice Streak
- Track consecutive days of practice.
- Build a regular English-learning habit.
- See your current streak on the home screen.

### 🌙 Light & Dark Themes
- Switch between light and dark mode.
- Your theme preference is saved for future visits.
- The app can also follow your device's colour-scheme preference initially.

### 📱 Installable Web App
- Designed to work across mobile phones, tablets, and desktop screens.
- Supports Progressive Web App (PWA) installation where available.
- Add P.K PRACTICE to your device for a more app-like experience.

### 👤 Personalised Entry
- Enter a name to get started.
- Your name is remembered on the device for subsequent visits.

## 🚀 Getting Started

1. Open the [P.K PRACTICE website](https://parthakonai000.github.io/Group-verb-practice/).
2. Enter your name when prompted.
3. Choose **List**, **Learn**, or **Practice** to begin.
4. To play with a friend, open **Play with Friends**, create a room, and share its code.
5. Your friend can enter that code to join the match.

## 🕹️ How to Play with a Friend

1. Both players open the website.
2. One player enters a name and selects **Create a room**.
3. Share the displayed 4-digit room code with the other player.
4. The second player enters their name and the code, then selects **Join room**.
5. When both players are in the room, the quiz begins.
6. Answer the questions and compare the live scores.
7. View the final result when the round is complete.

> Real-time multiplayer requires an internet connection.
